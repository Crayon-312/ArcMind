# 唯一 MVP 能力与阶段边界收敛

## 业务目标

为 ArcMind 建立唯一 MVP（最小可用产品）定义和阶段退出顺序，让人类与 Agent（智能协作助手）能明确判断哪些能力必须先完成、哪些属于后续增强，避免任务、语音、记忆和工作机同时铺开。

## 用户确认

- 2026-08-14，用户选择“语音任务版”作为 MVP。
- MVP 包含账号密码、文字对话、任务草稿与确认、任务状态与结果、实时语音和用户打断。
- 长期记忆、提醒和工作机执行明确后置。

## 工作区模式

当前工作区串行实施，不创建 Git worktree（Git 独立工作树）。本任务只修改项目知识和协作门禁，不修改产品运行代码或生产环境。

## 发布边界

- 本任务只确认目标设计和阶段顺序，不表示任务或实时语音已经实现。
- 当前生产状态仍以最近一次有证据的发布记录为准。
- 工作机、长期记忆和提醒不得通过 MVP 名义提前进入实施。
