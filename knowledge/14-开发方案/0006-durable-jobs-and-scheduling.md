## 目标

在创建云端代码骨架前，确定内部后台工作的队列技术、状态语义、重试和恢复策略，并明确用户任务、工作机执行租约和提醒调度不由队列状态替代。

## 非目标

- 不创建 Worker、Scheduler、数据库表或 Docker 容器。
- 不确定 LangGraph PostgreSQL Checkpoint 的初始化和清理策略。
- 不确定身份、HTTPS、实时事件通道或模型供应商。
- 不把完整业务任务改造成 Temporal Workflow（Temporal 工作流）。

本任务属于 S3 架构决策。按用户要求继续在当前 `v2` 主工作目录串行处理；任务开始时工作区干净，没有并行 Codex 任务或共享文件冲突，因此不新建 Git worktree（工作树）。
