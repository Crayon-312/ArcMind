## 目的

同一概念在手机端、云端、工作机和模型供应商中可能有不同叫法。本文件定义项目统一语言；接口和代码命名应以这里的语义为准，再由适配层映射外部供应商术语。

## 产品术语

| 中文名称 | 推荐代码名 | 定义 | 不等同于 |
|---|---|---|---|
| 用户 | `User` | 使用 ArcMind 的自然人主体 | 某次浏览器会话或某台设备 |
| 贾斯汀 | `AssistantPersona` | 用户感知到的统一助理人格与交互身份 | 某一个实时语音模型 |
| 会话 | `Conversation` | 一段有开始、上下文和结束边界的交互 | 单个任务或长期记忆 |
| 轮次 | `Turn` | 会话中一次用户输入或 AI 输出 | 音频分片或转写增量 |
| 会话摘要 | `ConversationSummary` | 本次会话已确认目标、约束和开放问题的压缩表示 | 原始聊天全文 |
| 长期记忆 | `Memory` | 经筛选、可追溯、跨会话复用的稳定事实 | 全量对话日志或向量索引 |
| 任务草稿 | `TaskDraft` | 讨论形成但尚未获得执行确认的目标和计划 | 正式任务 |
| 任务 | `Task` | 用户确认后由任务编排器维护的工作目标 | 模型的一段自然语言承诺 |
| 任务步骤 | `TaskStep` | 具有依赖、状态和验收条件的最小编排单元 | 执行器内部每条日志 |
| 执行尝试 | `Execution` | 某个步骤在云端工具或工作机上的一次实际运行 | 任务本身 |
| 执行租约 | `ExecutionLease` | 执行器在限定版本和时间内获得的步骤执行权 | 队列 Worker 的内部锁 |
| 后台作业 | `Job` | 云端内部可领取、可重试、可延迟的短工作 | 用户任务或长时间工作机进程 |
| 审批 | `Approval` | 用户对具体高风险动作和范围的限定决定 | 对未来所有动作的永久授权 |
| 工作机 | `Workstation` | 用户绑定并可选安装 ArcMind 执行端的电脑 | 云端后端或任意远程服务器 |
| 工作机客户端 | `WorkstationClient` | 安装在工作机上，负责连接、权限、执行和结果回传的软件 | 单独的安装器或通用远程桌面 |
| 能力 | `Capability` | 工作机或云端工具声明可以完成的一类受控工作 | 任意命令执行权限 |
| 产物 | `Artifact` | 任务生成并可被引用、下载或在本地定位的结果 | 完整本地工作目录 |
| 提醒 | `Reminder` | 按计划时间触发的用户事项 | 任务状态通知 |
| 通知 | `Notification` | 告知用户任务、审批、提醒或系统变化的消息 | 唯一业务事实 |

## 运行时术语

| 名称 | 定义 |
|---|---|
| 实时语音层 | 负责低延迟音频输入、输出、打断和稳定转写的交互层 |
| 主 Agent | 负责目标理解、上下文检索、方案形成和工具选择的产品运行时角色 |
| 任务编排器 | 负责任务事实、状态机、依赖、租约、重试和审批的确定性模块 |
| 执行器 | 在明确范围内调用某个云端能力或本地工具的适配器 |
| 供应商 | 提供模型、实时语音、存储或通知能力的外部服务方 |
| 适配器 | 把外部供应商或工具的私有协议转换成 ArcMind 稳定契约的模块 |
| JobQueue | 隔离 Procrastinate 等队列实现的内部作业端口 |

## 开发协作术语

- Agent Context OS：规范 Codex 等开发工具如何维护仓库的外部开发协作引擎。
- ArcMind Agent Runtime：服务最终用户的产品运行时。
- 两者不得简称为同一个“Engine”后直接混用；文档和代码必须带上“开发协作”或“产品运行时”限定语。

## 一致性规则

- `TaskDraft` 只有用户确认后才能生成 `Task`。
- `Task` 与 `Execution` 分离，一个步骤可以有多次执行尝试。
- `Task` 与 `Job` 分离，队列处理完成不能代表用户任务完成。
- `ExecutionLease` 与 Worker 内部锁分离，租约过期不能证明旧执行器已经停止。
- `Memory` 与检索索引分离，索引可以删除重建。
- `Reminder` 与 `Notification` 分离，通知失败不能抹掉提醒触发事实。
- 供应商的 `session`、`response` 和 `tool call` 必须由适配层映射，不能直接替代 ArcMind 领域对象。
- “工作机安装端”不是独立业务端；安装与升级属于工作机客户端的一个子组件。
