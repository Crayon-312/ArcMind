## 职责

- 提供后台预置账号的登录、退出和会话恢复界面；不提供公共注册入口。
- 请求麦克风权限，采集并发送实时音频。
- 播放实时语音，支持用户打断和本地播放队列清理。
- 展示连接、收听、处理中、说话、等待确认、断线和错误状态。
- 显示任务摘要并收集用户明确确认。
- 查看任务列表、步骤、实时进度、结果和阻塞原因。
- 展示消息、提醒和需要用户处理的事项。
- 在语音不可用时提供文字降级入口。

## 不负责

- 不保存唯一一份长期记忆或任务事实。
- 不在浏览器里实现完整主 Agent 和任务调度器。
- 不直接连接工作机、拼装本地命令或管理本地工具权限。
- 不假设页面关闭或退到后台后仍能持续实时通话。
- 不将供应商私有事件直接扩散到业务页面。

## 页面边界

| 页面 | 核心内容 |
|---|---|
| 身份入口 | 单一账号密码登录、会话恢复和异常提示 |
| 实时会话 | 音频状态、文字摘要、打断、静音和结束 |
| 任务中心 | 任务状态、步骤、进度、结果和审批 |
| 消息中心 | 完成、失败、阻塞、提醒和系统消息 |
| 设置 | 语音偏好、记忆管理、设备列表和隐私设置 |

第一阶段身份目标只实现后台预置的单一账号密码输入、会话失效、新建文字会话和文字会话状态；各状态的可执行动作、重连、取消和错误展示以[第一阶段手机页面与状态地图](./02-第一阶段手机页面与状态地图.md)为准。账号密码版本已经完成生产部署和公网验收；第一版视觉继承当前只在本地仓库完成验证，尚未推送或部署生产。

## 视觉继承基线

- 手机 Web 的 ArcMind 视觉事实源是 `main` 主分支第一版 Electron（桌面应用框架）前端，不再自行设计另一套普通聊天皮肤。
- 中心粒子弦核、环境网格、模式颜色、呼吸与轨道运动、工作台式回应区和悬浮输入动画继承第一版实现；移动端只调整尺寸、面板方向、安全区域和触摸可达性。
- 视觉继承不等于业务回退：Electron 本地存储、桌面桥接、模型设置、旧记忆和工作台业务不得进入 V2 手机运行链路。
- 文字回复视觉信号只能来自真实会话状态和真实 SSE（服务器发送事件）增量；禁止使用定时器生成随机音频、随机思考脉冲或其他伪业务信号。
- 流式文本更新不得重建 Three.js（网页三维图形库）场景或增加动画循环；同一页面生命周期只保留一个粒子画布实例。
- 第一版输入区默认收起：桌面端鼠标进入底部热区后弹出，手机端只显示底部小横条并在点击后弹出；发送成功后重新收起，生成中的取消操作保持独立可达。

## 浏览器约束

- 生产环境麦克风、Service Worker（服务工作线程）和 Web Push（网页推送）通常要求可信的 HTTPS（超文本传输安全协议）安全上下文。
- 自签名证书只有在每台设备显式信任对应根证书后才可能形成可信上下文；直接忽略浏览器警告不能作为稳定部署方案。
- 首版采用固定公网 IPv4 和公开短期 IP 证书；普通域名、受管理私有证书和受信任隧道保留为失败替代方案。
- IP 证书必须经过无 SNI 客户端、安全 Cookie、`isSecureContext` 和真实手机麦克风权限验证。
- iOS 浏览器对后台音频、推送安装形态和媒体自动播放存在额外限制，必须在真实设备验收。
- 首版只保证页面前台通话；退到后台后中断应被视为正常边界并给出提示。

## 实时会话状态

```text
idle -> connecting -> listening <-> processing <-> speaking
                     speaking -> interrupted -> listening
任意活动状态 -> reconnecting -> 活动状态或 failed
任意活动状态 -> ended
```

状态展示必须来自会话控制器，不得只根据动画或本地录音状态推测服务器状态。

## 打断规则

1. 用户开始说话或主动点击打断时，立即停止本地未播放音频。
2. 向实时会话发送取消当前响应的控制事件。
3. 标记被打断响应，后续迟到音频不得继续播放。
4. 保留已确认文本，未确认的半句不能直接形成可执行任务。
5. 会话恢复到收听或处理中，并在界面明确显示。

## 验证重点

- iOS Safari、Android Chrome 和常见国产浏览器真机测试。
- 首次授权、拒绝授权、撤销授权和设备无麦克风。
- 耳机切换、来电打断、锁屏、切后台和弱网重连。
- AI 说话早期、中期和结束瞬间的用户打断。
- 页面刷新后任务状态恢复，不重复提交确认操作。
- 文字增量到达前后粒子画布实例稳定，模式变化平滑且不存在随机闪动。
