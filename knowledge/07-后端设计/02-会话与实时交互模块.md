## 职责

管理文字与实时语音会话、轮次、转写最终性、会话摘要、响应取消和供应商会话映射。

## 不负责

不直接创建正式任务，不维护长期记忆最终事实，不决定工作机执行范围。

## 允许依赖

- 实时语音适配器。
- 主 Agent Runtime。
- 记忆检索公开接口。
- 会话持久化和实时事件总线。

## 禁止依赖

- 供应商事件直接修改任务状态。
- 临时转写直接写入长期记忆。
- 在会话模块中实现供应商专属业务分支。

## 数据流

```text
手机输入 -> 会话标准化 -> 主 Agent -> 响应事件 -> 手机播放/展示
供应商转写 -> 最终性判断 -> Turn -> 会话摘要候选
```

文字响应通过普通 HTTPS 创建，再由 SSE 返回快照、增量和终态。模块在 `ModelResponse` 中周期性保存可恢复完整快照和生成状态，单个增量只进入有限重放窗口，最终助手轮次单独保存；供应商流和浏览器连接都不能成为唯一事实源。

## 验证方式

- 文字轮次、转写增量、最终转写、打断、重连和重复事件测试。
- 供应商适配契约测试和录制事件回放。

## 常见风险

- 临时和最终转写重复入库。
- 会话断线后旧响应污染新连接。
- 供应商会话标识泄漏到领域 API。
