## 身份与会话

| ID | 层级 | 场景 | 必须证明 |
|---|---|---|---|
| ID-001 | 单元 | 账号归一化与密码校验 | 账号大小写和空白处理一致；正确密码通过，错误密码失败 |
| ID-002 | 契约 | 登录统一错误 | 错误账号与错误密码均返回 `AUTH_INVALID_CREDENTIALS`，不泄露账号状态 |
| ID-003 | 集成 | 密码安全存储 | 数据库只含抗暴力密码哈希，不含明文、可逆密文或默认密码 |
| ID-004 | 集成 | 并发登录 | 并发正确登录可创建独立会话，不产生共享原始令牌或异常数据库状态 |
| ID-005 | 集成 | 最小登录限速 | 连续失败触发安全等待，正常本人使用不被复杂挑战流程阻塞 |
| ID-006 | 集成 | 会话生命周期 | 空闲 7 天、绝对 30 天、当前退出和全部撤销边界正确 |
| ID-007 | 端到端 | Cookie（浏览器会话凭据）属性 | 只有 `__Host-arcmind_session`，具备 `Secure`、`HttpOnly`、`SameSite=Lax`、`Path=/` 且无 `Domain` |
| ID-008 | 端到端 | 会话失效 | 普通请求和事件流同时停止，页面回到登录且不复用旧游标 |
| ID-009 | 安全 | 日志和审计 | 密码、原始会话令牌和密码哈希不进入日志、错误或追踪 |

## 文字响应与恢复

| ID | 层级 | 场景 | 必须证明 |
|---|---|---|---|
| TXT-001 | 集成 | 提交文字轮次 | 用户轮次与响应记录原子创建，重复幂等键不产生重复轮次或计费 |
| TXT-002 | 契约 | 正常事件序列 | started、snapshot、delta、completed 均通过 Schema，序号单调且事件 ID 稳定 |
| TXT-003 | 契约 | 非法载荷 | 缺字段、错误类型、未知字段和错误事件专属字段均被拒绝 |
| TXT-004 | 端到端 | 最终恢复 | 关闭事件流或刷新页面后，最终助手轮次可从会话详情恢复 |
| TXT-005 | 集成 | 快照节流 | 生成中最多 500 毫秒或新增 256 字符形成完整快照，单个增量不入最终轮次 |
| TXT-006 | 端到端 | 不同序号断线重连 | 携带 `Last-Event-ID` 后先收到权威快照，再处理更高序号增量 |
| TXT-007 | 端到端 | 重复与缺口 | 重复事件不重复文本；序号缺口触发快照替换而非继续拼接 |
| TXT-008 | 集成 | 进程重启 | 已完成响应可恢复；遗留生成转为可重试失败，不伪造最终轮次 |
| TXT-009 | 集成 | 幂等取消 | queued 和 generating 均可取消；重复取消同结果，迟到增量不能覆盖终态 |
| TXT-010 | 端到端 | 重放窗口过期 | 客户端丢弃临时文本并重新查询事实，不展示残缺回答为完成 |
| TXT-011 | 集成 | 模型超时、限流和不可用 | 保留用户轮次与稳定错误类别，允许显式重试且不自动切换供应商 |
| TXT-012 | 集成 | 同一会话并发提交 | 同时提交不同请求时只接受一个生成中响应，另一个返回稳定冲突 |
| TXT-013 | 集成 | 相同幂等键并发重试 | 只创建一个用户轮次、响应和 Job，所有调用返回同一业务结果 |
| TXT-014 | 端到端 | 连续提问 | 前一响应未结束时按契约拒绝冲突，不创建两个污染同一轮次的回答 |

## 契约与数据

| ID | 层级 | 场景 | 必须证明 |
|---|---|---|---|
| CON-001 | 契约 | OpenAPI 解析与引用 | 3.1 文档可解析，所有引用可解析，无重复 `operationId` |
| CON-002 | 契约 | 正反样例校验 | 每个公开 Schema 至少一个通过样例；关键边界至少一个失败样例；测试运行时显式启用格式断言 |
| CON-003 | 契约 | 服务端差异 | FastAPI（Python 接口框架）生成契约与审定契约无未批准差异 |
| CON-004 | 契约 | 客户端类型 | TypeScript（类型化网页语言）类型只由审定契约生成并能通过类型检查 |
| DATA-001 | 集成 | 登录会话事务 | 密码验证成功后原子创建会话；验证失败不产生会话或修改业务数据 |
| DATA-002 | 集成 | 响应完成事务 | `completed` 必有一个最终助手轮次；失败回滚不产生半完成状态 |
| DATA-003 | 集成 | 所有权与越权 | 当前用户不能通过猜测标识读取或取消其他用户资源，统一返回安全错误 |
