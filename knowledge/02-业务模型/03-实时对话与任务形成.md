## 主流程

| 步骤 | 用户动作 | 系统行为 | 输出 |
|---|---|---|---|
| 1 | 打开手机 Web 并开始通话 | 校验会话，建立实时连接 | 进入收听状态 |
| 2 | 用自然语言表达想法或任务 | 实时语音层生成转写，主 Agent 识别意图 | 对话回复或澄清问题 |
| 3 | 补充目标、约束和期望结果 | 主 Agent 更新会话摘要，不立即执行 | 可复述的已确认信息 |
| 4 | 要求开始处理 | 主 Agent 形成任务草稿和验收条件 | 任务确认卡片和语音摘要 |
| 5 | 确认任务 | 任务编排器创建正式任务并选择执行路径 | 任务编号和当前状态 |
| 6 | 结束通话或继续聊天 | 云端异步执行，手机可随时查询 | 进度、阻塞或结果消息 |

## 对话类型

| 类型 | 判断依据 | 默认处理 |
|---|---|---|
| 普通聊天 | 没有形成明确任务目标 | 继续对话，必要时形成候选长期记忆 |
| 即时查询 | 单步、低风险且可快速返回 | 由主 Agent 调用云端受控工具 |
| 任务讨论 | 存在目标但约束或验收未明确 | 继续澄清，保持任务草稿 |
| 可执行任务 | 目标、范围和验收明确且用户确认 | 创建任务并进入调度 |
| 进度查询 | 用户询问已有任务 | 查询任务事实并反馈，不凭模型猜测 |
| 任务变更 | 用户修改已确认目标 | 创建计划变更并评估对执行中步骤的影响 |

## 打断流程

| 场景 | 系统行为 | 业务影响 |
|---|---|---|
| 用户在 AI 说话时开口 | 停止播放并取消当前响应 | 未播报部分不视为用户已知或已确认 |
| 用户点击停止 | 停止播放并回到收听或空闲 | 保留已确认的会话事实 |
| 取消事件迟到 | 通过响应标识丢弃旧音频 | 不得覆盖新一轮对话状态 |
| 打断发生在任务摘要中 | 标记摘要未完成 | 必须重新确认后才能创建任务 |

## 异常流程

| 异常 | 系统行为 | 是否可重试 | 用户可见结果 |
|---|---|---:|---|
| 麦克风不可用 | 提供权限指引和文字入口 | 是 | 明确说明语音不可用 |
| 实时连接失败 | 分类为浏览器、网络、云端或供应商故障 | 是 | 提供重连和文字降级 |
| 主 Agent 超时 | 保留转写和会话状态 | 是 | 说明处理暂时失败，不创建任务 |
| 任务创建失败 | 使用幂等键重试或返回失败 | 是 | 不显示虚假的任务编号 |
| 手机断线 | 云端结束或暂存实时会话，保留已创建任务 | 是 | 重连后恢复任务事实 |

## 禁止流程

- 不得把背景聊天自动升级为执行授权。
- 不得由实时语音供应商直接修改正式任务状态。
- 不得在任务草稿尚未确认时派发工作机执行。
- 不得将“我去处理”播报为已经开始执行，除非任务表已进入对应状态。
- 不得因为对话被打断而丢失已经持久化的任务事件。
