# ArcMind 知识库

在 Obsidian（本地 Markdown 知识库工具）中打开 `D:\ArcMind\knowledge`。Git（版本控制工具）中的 Markdown 文件是事实源，Obsidian 负责阅读、链接和关系图，Agent Context OS（智能协作上下文操作系统）负责校验、索引和检索。

## 知识发布闭环

```text
问题或需求
  -> draft 任务舱中调查和形成有序清单
  -> 用户确认后进入 active
  -> 按任务 ID 实施代码、配置和知识变更
  -> 真实行为与质量门禁验证
  -> 正式领域更新为当前事实
  -> 发布记录与任务舱一起闭环
```

讨论阶段不得直接修改正式事实。目标契约先进入任务舱；实现和正式知识在同一任务中完成，验证通过后一起发布。

## Agent 检索

```powershell
pnpm context:validate
pnpm context:index
pnpm context:search -- "任务调度"
```

本地索引只是可删除、可重建的定位缓存，不是事实源。任务舱、模板、归档和附件不进入正式知识索引。

## 关系图阅读

关系图的稳定层次是“总地图 → 领域地图 → 领域知识 → 跨领域语义关系”。Canvas（Obsidian 可视化画布）、标签和筛选只是视图，不能替代 Markdown 链接、任务状态和验收证据。
