# 当前事实、登录方式与变更入口

本页回答容易被草稿、历史记录或相似术语干扰的高频问题。这里只做路由和结论摘要，详细依据仍以链接指向的当前知识、代码与测试为准。

## 讨论阶段能否修改正式文档

不能。开发协作 Agent（智能协作助手）在纯讨论阶段只能修改状态为 `draft` 的[任务舱](../14-开发方案/00-开发方案地图.md)，不能修改正式知识、代码或配置。用户确认完整方案和有序任务清单后，任务舱才能进入执行；代码与正式知识在同一任务中验证并一起发布。

这里的开发协作 Agent 与 ArcMind 产品中的[主 Agent 运行时（草案）](../20-Agent运行时/02-主Agent运行时模块.md)不是同一个系统。产品主 Agent 的业务权限规则不能替代开发协作门禁。

依据：[知识库维护规范](./知识库维护规范.md)、[Obsidian 任务隔离决策](../10-架构决策/0010-obsidian-task-publication.md)。

## 当前应该怎样登录

当前代码、OpenAPI（开放式接口描述规范）、手机 Web 和数据库迁移已经改为单一账号密码登录，不再依赖邮箱验证码或 SMTP（简单邮件传输协议）投递。真实 PostgreSQL（关系型数据库）集成验证已经覆盖旧用户绑定、密码轮换、会话并发和两档数据库权限；当前生产仍暂时运行验证码旧版本，尚未执行部署切换和公网验收，不能把“本地已实现”误报为“已经上线”。

依据：[单一账号密码身份基线](../10-架构决策/0018-simple-login-identity.md)、[账号密码迁移任务舱](../14-开发方案/0016-simple-login-and-database-hardening.md)。邮箱验证码旧方案只保留为已废弃决策和归档历史，不进入当前运行手册。

## 当前生产模型是什么

线上当前仍使用确定性测试模型。DeepSeek V4 Pro（深度求索主模型候选）已经被选为首个真实主 Agent 模型，但尚未配置生产密钥，也没有接入当前生成请求路径，因此“已经选型”不能表述为“已经在生产启用”。

依据：[首个模型供应商决策](../10-架构决策/0015-first-model-provider.md)、[安全与部署边界](../08-安全与合规/01-安全与部署边界.md)。

## 新增或修改 API 需要同步什么

非平凡 API（应用程序接口）变更先建立或更新任务舱，然后按以下顺序执行：

1. 在[接口与事件地图](../04-接口与事件/00-接口与事件地图.md)确认业务语义、公开边界、兼容性和错误码。
2. 修改 `knowledge/04-接口与事件/openapi/phase-1.yaml` 或对应机器 Schema；它们是审定契约输入。
3. 运行 `pnpm contracts:generate`，更新 `packages/contracts/src/generated/` 生成类型，不手工复制字段。
4. 同步云端实现、手机 Web 消费方及受影响的前后端设计；跨模块调用不得绕过公开契约。
5. 更新契约、后端、前端和端到端测试，并按[测试与验收地图](../11-测试与验收/00-测试与验收地图.md)验证兼容与失败路径。
6. 验证通过后同步领域地图、当前知识、任务舱和[发布记录](../15-发布记录/00-发布记录地图.md)。

讨论中的接口候选只能留在任务舱或明确标记为草稿的契约文档中，不能提前覆盖机器契约或当前运行事实。
