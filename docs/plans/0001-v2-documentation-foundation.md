# 方案落实台账：ArcMind V2 文档基线

状态：active
最后更新：2026-07-30

## 目标

在独立 `v2` 分支从零建立基于 Agent Context OS 极薄启动器的开发协作入口，并将已确认的 V2 产品方向拆成可审查的产品、架构、业务、契约、决策和质量文档。

## 非目标

- 不编写手机端、云端或工作机端业务代码。
- 不复用或迁移 `main` 的旧代码和旧项目事实。
- 不在本轮确定具体技术栈或实时语音供应商。
- 不把 Agent Context OS 变成 ArcMind 产品运行时依赖。

## 已确认点

- `main` 与 `v2` 双线并存，当前主要方向为 `v2`。
- `v2` 从零开始且不继承旧项目内容。
- 先搭建文档体系，代码后续再做。
- 文档必须区分手机 Web、云端后端和可选工作机端职责。
- Agent Context OS 只用于 Codex 等工具开发本项目时的规范。

## 开放问题

- 首个实时语音供应商和实测基线。
- 手机 Web、云端、数据库和工作机端技术栈。
- 可信 HTTPS 部署方式。
- 长期记忆写入阈值和数据保留期。

开放问题不阻塞本轮文档基线，但在对应开发阶段前必须形成已确认决策。

## 多 Agent 说明

本任务未启用子 Agent：当前执行规则不允许主动委派，且分支创建、文档交叉引用与门禁验证需要由单一主 Agent 串行保持一致。
