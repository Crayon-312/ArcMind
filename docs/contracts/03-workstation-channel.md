## 目标

工作机通过主动出站的持久连接接入云端。本契约定义连接阶段、能力注册、任务租约和结果事件的稳定语义，不锁定具体网络库。

## 连接生命周期

```text
disconnected
  -> connecting
  -> authenticating
  -> registering
  -> online
  -> draining
  -> disconnected

任意握手状态 -> rejected
online -> reconnecting -> online 或 disconnected
```

## 握手阶段

1. 工作机连接唯一公开设备网关。
2. 双方确认协议版本和服务器身份。
3. 工作机证明其已绑定设备身份，云端校验是否仍有效。
4. 工作机上报客户端版本、操作系统摘要和能力清单。
5. 云端返回连接标识、心跳间隔、最大消息限制和服务器时间。
6. 双方进入 `online` 后才允许任务租约流转。

## 能力描述

| 字段语义 | 说明 |
|---|---|
| capability_type | 稳定能力类型，例如受控编程或文档处理 |
| capability_version | 能力契约版本 |
| adapter | 本地执行器名称和版本 |
| constraints | 支持的工作区、并发、平台和资源限制摘要 |
| approval_modes | 该能力支持的本地或远程确认方式 |
| health | 当前是否可接收新任务及原因 |

能力清单只描述可以做什么，不包含本地私密文件列表。

## 任务租约

`execution.lease.offered` 至少包含：

- 任务、步骤和执行尝试标识。
- 租约版本、创建时间和过期时间。
- 所需能力类型和最低版本。
- 结构化目标、输入引用、验收条件和资源预算。
- 允许访问的工作区范围。
- 已批准动作摘要；未批准动作不得默认为允许。
- 幂等标识和事件关联标识。

工作机必须明确返回接受或拒绝。拒绝需要稳定原因，例如能力不匹配、设备繁忙、工作区不可用或需要本地确认。

## 执行事件

| 事件 | 必需语义 |
|---|---|
| `execution.started` | 执行标识、开始时间、适配器版本 |
| `execution.progressed` | 阶段、进度摘要、检查点、可取消状态 |
| `execution.approval.required` | 具体动作、目标、影响、建议和过期时间 |
| `execution.artifact.produced` | 产物类型、名称、大小摘要和受控引用 |
| `execution.completed` | 结果摘要、验收证据和结束时间 |
| `execution.failed` | 错误类别、可重试性、检查点和清理状态 |
| `execution.cancelled` | 取消来源、已停止范围和保留产物 |

## 可靠性规则

- 每条消息具有唯一事件标识，双方按事件标识去重。
- 连接重建后工作机先上报未完成执行，再接受新租约。
- 云端对同一执行尝试只允许一个有效租约版本。
- 旧连接、旧租约和过期审批产生的事件可以记录，但不能推进当前状态。
- 进度事件可以合并，开始、审批、完成、失败和取消事件不能丢失。
- 取消是请求而不是瞬时事实，只有工作机确认清理结果后更新执行终态。

## 流量与隐私边界

- 默认回传结构化摘要，不持续上传完整终端输出。
- 产物优先保留在本地，通过受控引用按需下载或摘要。
- 云端不得请求能力声明之外的目录和动作。
- 工作机不得把本地环境变量、无关目录、其他项目或系统信息放入心跳。
- 诊断包必须由用户明确触发并允许预览范围。

## 升级兼容

- 握手声明协议版本范围，无法兼容时拒绝并给出升级原因。
- 新增可选字段必须保持旧客户端可忽略。
- 改变事件语义、权限范围或必需字段时升级主版本。
- 云端升级需要保留至少一个受支持的旧工作机协议窗口。

## 待定项

- WebSocket、gRPC（远程过程调用）流或其他传输实现。
- 设备身份材料和轮换机制。
- 工作机自动更新、签名和回滚方案。
- 本地沙箱与工作区授权的具体实现。
