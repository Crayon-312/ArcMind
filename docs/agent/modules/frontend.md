# 模块：Renderer Frontend

## 模块职责

Renderer 负责 React 界面、对话体验、设置、历史、记忆管理、状态展示和用户交互。

不负责直接访问 Node API、文件系统、数据库、系统密钥或模型 API Key。

## 公共接口

- 只通过 preload 暴露的 typed `window.arcMind` 获取能力。
- 与视觉系统通过状态和事件通信，不直接操纵底层模型请求。

## 数据与状态

- 管理页面级状态、表单状态、聊天渲染状态和用户操作反馈。
- 模型流式内容应可停止、重试和错误恢复。
- 当前 renderer 通过 `window.arcMind.chat` 发送消息、订阅 token、停止生成；流式订阅必须按 `requestId` guard，并在切换、清空、删除会话或组件卸载时取消旧请求和释放监听，避免旧回复污染当前会话。通过 `window.arcMind.settings` 保存/测试模型配置，页面只展示是否已配置 API Key。
- 设置面板的“测试连接”应传入当前表单草稿；用户不必先点击保存才能测试刚输入的 API Key。
- 设置面板将文字模型与 GPT-Live 实时语音分区展示。实时语音区域必须明确“仅限 codex-LB”，支持检测当前草稿；修改地址或密钥后立即清除旧检测结果并关闭草稿中的启用开关。
- 应用读取到已配置的实时语音后会自动检测。只有 `available` 状态允许操作启用开关，其他状态必须展示可理解的原因，且不能只靠颜色表达。
- 当前会话历史使用左上角极小不可见热区触发抽屉，默认隐藏以减少对弦核视觉的遮挡；抽屉打开状态会传给 `ParticleCore` 用于轻微视角偏转，首屏不显示历史图标按钮。
- 当前设置、记忆、回应状态和播报开关收纳在右上角极小热区触发的图标工具 rail；工具 rail 只负责唤出按钮本身，点击按钮后再从右侧弹出设置、记忆或工作台面板，默认首屏不常驻顶部栏、聊天框或密集 HUD。
- 当前输入栏使用底部小型识别区 hover/focus 自动弹出，并保留点击把手兜底；点击说话仍保留在输入栏内，不作为持续可见控件。没有草稿时，鼠标和键盘焦点离开后输入栏直接隐藏；已有草稿时输入栏保持可见，用户可通过顶部中间的向下箭头手动收起且不清理文本；录音或转写进行中时保持可见。输入栏不通过大面积 hover 区触发，避免鼠标误触和高频状态切换；弹出时把 `composerOpen` 传给 `ParticleCore`，仅在关闭到打开的瞬间触发一次以上沿为源头的 3D 波前反馈。CSS 层必须在输入框外部提供 `composer-impact` 和 `composer-source-ripple` 两层视觉证据：上沿爆亮、火花上冲和透视波面都锚在输入框上沿，不进入输入框内部。
- 当前右侧工作台会在用户发送后立即自动滑出并承接流式回复；renderer 使用本地 typewriter reveal 队列平滑展示模型 delta，即使供应商一次 flush 大段内容也不能整段弹出。完成后无论是短回答、报告、长 Markdown 还是选择块，都保留在工作台内。Markdown 渲染标题、无序/有序列表、表格、代码块和链接；显式 `:::choices` 或带选择语义的末尾编号/项目列表会转成按钮，按钮值写回输入草稿并沿用现有对话发送流程。
- 当前 renderer 提供 `?view=system-lab` 系统状态空间实验台，用于讨论 CPU、内存、磁盘和 GPU 状态在小型透明 3D 投影面板中的呈现方向；面板保持单个、精简、低占比，避免抢占弦核焦点。Electron 环境读取 `window.arcMind.system.getTelemetrySnapshot()`，浏览器环境自动使用合成示例数据。

## 边界规则

- UI 必须遵守 `design-system.md`。
- 不在页面中显示 API Key、私密路径或不可删除的记忆内容。
- 输入、发送、停止、重试、静音和录音按钮必须有明确状态。
- 不得把文字模型连接测试结果复用为实时语音检测结果。
- 工作台标记只用于 renderer 展示协议，不得泄露供应商 HTTP shape；按钮选择必须回到普通用户输入流程。
- 隐式边缘控件的识别范围必须保持小而可预期；右上工具 rail 的 hover 状态不得驱动 `ParticleCore` 偏转，只有实际打开的右侧面板参与弦核重心偏移；底部输入只能触发一次性 composer 上沿波前 impulse，不得把 hover 高频状态持续映射到 3D 旋转。
- 输入框外部波面是输入弹出反馈的一部分，不是常驻装饰；隐藏窗口下的 smoke 不能依赖 CSS 动画运行帧，但必须检查强视觉层的动画名、宽度、时长和发光配置。
- 输入栏自动或手动隐藏只改变可见性，不得清空草稿、取消录音或打断正在进行的对话；所有隐藏式交互都必须优先考虑普通用户是否能自然理解和恢复操作。
- 系统状态空间实验台只能消费结构化遥测快照或合成示例数据，不得在 renderer 直接读取 Node、文件系统、系统命令或硬件接口。

## 验证要求

- 组件测试或交互测试。
- 窄窗口和桌面窗口手动检查。
- 视觉层叠检查：粒子不得遮挡对话和按钮。
