## 信任边界

ArcMind 跨越公网浏览器、云端服务、外部模型供应商和用户工作机。任何一段连接都不能因为“个人项目”而默认可信。

| 边界 | 主要风险 | 基线控制 |
|---|---|---|
| 手机浏览器到云端 | 会话劫持、窃听、重放 | 可信 HTTPS、短期会话、来源校验、速率限制 |
| 云端到模型供应商 | 数据外发、供应商故障、用量失控 | 最小数据、适配层、超时、限额和审计 |
| 工作机到云端 | 设备冒充、命令重放、连接劫持 | 设备绑定、双向校验、任务租约、序列和过期控制 |
| 云端到本地执行器 | 权限扩大、危险操作、敏感结果泄露 | 能力白名单、工作区限制、动作确认、结果过滤 |
| 管理与运维入口 | 高权限误用 | 独立管理边界、最小权限、审计和恢复流程 |

## HTTPS 基线

- 生产手机 Web 必须运行在浏览器认可的安全上下文中。
- 单纯为 IP 地址生成自签名证书并让用户忽略警告，不是稳定方案。
- 首版选择固定公网 IPv4、Caddy v2.11.4 或更高兼容版本，以及 Let’s Encrypt `shortlived` 公网 IP 证书。
- Caddy 必须显式选择公开 ACME 签发器、短期配置档和 `default_sni`；证书状态使用持久卷保存。
- 160 小时证书必须自动续期并每天检查，剩余有效期低于 48 小时告警。
- 当前共享 VPS 只允许 ArcMind 使用公网 18443，该端口不能完成公开 IP 证书的 ACME 自动校验；此部署只用于兼容性验证，生产必须改用域名 DNS 自动校验、ArcMind 独立服务器或经用户确认的可信隧道，并且不得修改现有项目的 80/443 入口。
- 最终方案需同时验证安全 Cookie、麦克风、实时媒体、Service Worker 和 Web Push 在目标 iOS/Android 浏览器中的行为。
- 证书自动续期只解决有效期，不会自动解决设备信任问题。

## 身份与会话基线

- 首版只允许部署配置中的一个归一化邮箱，不开放公共注册。
- 一次性验证码短期有效、限制尝试、成功即消费；验证码和原始会话令牌不得落入日志或数据库明文。
- Web 会话使用服务端可撤销令牌摘要和 `__Host-` 安全 Cookie，支持当前退出、全部撤销、空闲过期和绝对过期。
- 会话撤销必须同步终止实时事件连接；限速和来源校验不能因“仅本人使用”而关闭。

## 工作机安全基线

- 工作机只建立出站连接，不开放通用远程控制端口。
- 云端下发的是结构化任务包，不是任意终端文本。
- 每次执行限制能力、工作区、有效期和资源预算。
- 高风险动作进入等待确认状态；确认与具体动作绑定。
- 执行器进程采用最小系统权限，优先在受控工作区或沙箱运行。
- 本地私密内容默认不上传；只回传任务必需摘要与产物引用。

## 云端部署基线

- 首版允许单 VPS、多容器部署，公网只暴露反向代理入口。
- 数据服务和内部管理端口不直接暴露公网。
- 开发、测试和生产配置分离，仓库不保存真实运行配置值。
- 提供健康检查、结构化日志、备份、恢复演练和升级回滚步骤。
- 外部供应商故障不能导致任务事实丢失或无限重试。

## 用户控制

- 用户可查看已绑定工作机和最近活动。
- 用户可撤销设备关系、停止任务和拒绝待确认动作。
- 用户可查看、更正或删除长期记忆。
- 用户可选择实时语音供应商和相应数据边界。
- 任何自动化提醒或后台任务都有可关闭入口。

## 开发前必须补齐

- 威胁模型和数据分类。
- 身份恢复、设备绑定与撤销流程。
- 高风险动作分类和审批有效期。
- 数据保留、删除、备份和恢复规则。
- 供应商数据处理与出境边界评估。
