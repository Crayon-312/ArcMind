# 模块卡片：身份与访问

状态：draft
最后校验日期：2026-07-30

## 职责

管理邮箱注册入口、登录与退出、Web 会话、身份恢复、设备绑定关系和访问控制。

## 不负责

不保存对话业务内容，不负责工作机能力调度，不决定任务执行策略。

## 允许依赖

- 用户与身份存储。
- 邮件投递适配器。
- 审计与速率限制能力。

## 禁止依赖

- 直接修改任务、记忆或会话内部数据。
- 把浏览器会话永久等同于用户主体。
- 让模型供应商承担 ArcMind 身份认证。

## 公开能力

- 注册与邮箱验证。
- 登录、续期、退出和全部会话撤销。
- 当前用户查询与偏好更新。
- 工作机绑定发起、确认、撤销和设备列表。

## 验证方式

- 注册、重复注册、登录失败、恢复、撤销和并发会话测试。
- 越权访问、重放、速率限制和设备解绑测试。

## 常见风险

- 邮箱枚举和暴力尝试。
- 会话撤销后实时通道仍保持有效。
- 工作机绑定码被重放或绑定到错误用户。
