# 模块卡片：任务编排

状态：current
最后校验日期：2026-07-30

## 职责

维护任务、计划版本、步骤依赖、执行尝试、租约、审批、重试、取消、状态事件和结果验收。

## 不负责

不与用户自由对话，不推理未表达的目标，不执行本地工具具体动作。

## 允许依赖

- 任务存储与事务。
- 云端工具网关和工作机网关。
- 通知模块。
- 审计与事件发布能力。

## 禁止依赖

- 直接读取手机页面状态决定任务状态。
- 使用模型播报结果作为执行完成证据。
- 绕过审批模块执行高风险动作。

## 数据流

```text
已确认计划 -> Task/Steps -> 调度与租约 -> Execution Events -> 聚合状态 -> 结果/通知
```

## 验证方式

- 完整状态机、依赖、幂等、乱序、租约过期、重试和取消测试。
- 高风险审批和终态不可逆测试。

## 常见风险

- 重复派发造成多次副作用。
- 迟到事件将终态回滚。
- 工作机断线时错误标记任务成功或失败。
