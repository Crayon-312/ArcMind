# 模块卡片：记忆服务

状态：draft
最后校验日期：2026-07-30

## 职责

管理候选记忆、来源、去重、冲突、有效状态、检索、更正、删除和索引重建。

## 不负责

不保存所有原始对话作为长期事实，不替代会话存储，不让检索索引成为唯一数据源。

## 允许依赖

- 记忆事实存储。
- 可替换的关键词、全文和向量检索提供器。
- 数据治理与删除流程。

## 禁止依赖

- 未经筛选把每个对话轮次自动永久化。
- 让模型输出直接覆盖高可信当前记忆。
- 将供应商专属向量格式暴露给上层。

## 数据流

```text
对话/用户更正 -> 记忆候选 -> 筛选与去重 -> 事实源 -> 可重建索引 -> 按需检索
```

## 验证方式

- 去重、冲突、更正、废弃、删除、索引重建和访问范围测试。
- 低可信记忆不能覆盖高可信事实的优先级测试。

## 常见风险

- 把推测当事实，形成长期错误上下文。
- 删除事实后索引残留。
- 检索返回过多无关私密上下文。
